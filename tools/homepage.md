# 边做边学 LLM 推理服务 { .home-title }

**从跑通服务，到解释为什么快。**

围绕一个可复现的 OpenAI 兼容推理服务，学习性能度量、vLLM/SGLang 调优、CUDA/Triton 算子优化，并以**昇腾 Ascend 为主线**学习国产芯片适配。每一步分别验证数值正确性、实际调用路径、用户体验与任务质量，最后形成一份跨平台对比报告。

## 你将得到什么

- **一套能复现的服务实验台**：启动、流式冒烟、压测、环境与原始记录。
- **一份能解释的优化记录**：瓶颈在哪、改了什么、是否真正生效、收益与代价是什么。
- **一个从算子到引擎的验证闭环**：不只写 kernel，还确认注册、分发、质量与端到端表现。
- **一份带边界的跨芯片报告**：同模型、同评测集、同负载；缺失证据和待测条件写清楚。

## 适合谁，需要什么

熟悉 Python、Transformer 和命令行的工程师；不要求先会 serving、Kubernetes 或 CUDA。环境门槛随路线变化，每章开头可展开“开始前”查看前置与产出。

- **无卡**：完成指标与数学推导，跑通完整 CPU mock SSE，建立实验记录。
- **有 GPU**：部署和度量真实模型，再选择框架或算子优化。
- **有 Ascend NPU**：先核对版本组合和冒烟，再做覆盖、迁移和回归。

本书区分纸面估算、CPU mock、参考配方和实机测量。正文中的“待验证”“待补测”不代表通过；[统一实验约定](docs/experiments.md)说明如何保留证据、判断收益与报告局限。
