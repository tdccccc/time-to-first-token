## 一、起源与演进

本在线书源自开源项目 [patchy631/time-to-first-token](https://github.com/patchy631/time-to-first-token) 的中文翻译与深度重构，仓库中完整保留了[上游英文原文归档](original-README.md)供对照查阅。

最初的上游仓库是一份极具启发性的 LLM 推理学习路线图与资料清单。在持续编写与迭代的过程中，我们将它进一步演进为一本结构完整、自成体系的中文在线精讲读物——**《LLM 推理工程：原理与方法》**：

- **聚焦原理直觉与工程判断**：用统一硬件与模型基线（A100 / H100 / 昇腾 910B + Llama-3.1-8B / Qwen3-8B，详参[硬件规格与模型账本速查](toolkit/hardware-models.md)）贯穿全书五篇 23 章，把 Roofline 物理直觉、显存与算力账本、引擎内部机制、GPU 内核阶梯和国产芯片适配串成一条连贯的主线；
- **独立沉淀前沿与工具横切区**：将五模型前沿架构拆账、大规模集群 PD（Mooncake/Splitwise）、端侧运行时、核心论文口径档案与国产芯片生态速查收进**进阶专题库**，将规格表、测量方法论与参考脚本配置收进**参考手册与工具箱**，做到主线清爽、延伸深入。

## 二、资料选用与口径原则

为了让读者获得经得起推敲的一手知识，全书在参考资料与数据引用上坚持四项原则：

1. **具名一手来源优先**：优先引用顶级系统会议论文（SOSP / OSDI / ISCA / FAST / NeurIPS / ICLR / MLSys）、知名高校公开课程（Stanford CS336、MIT 6.5940、GPU MODE）与推理引擎官方架构文档/核心开发者专栏。
2. **数字永远绑定条件**：任何论文或厂商博客的加速倍数、吞吐提升与延迟数字，都附带其对比基线、硬件规模、负载分布与统计分母（集中归档于[专题 D：各章核心论文精读与数据口径](topics/paper-notes.md)），不作脱离语境的绝对宣传。
3. **重方法论轻过期版本号**：GPU 租赁单价、推理引擎命令行参数以及国产芯片插件支持矩阵随季度快速演进；本书正文着力沉淀不随版本过时的物理算术、排查框架与架构权衡，具体最新命令与支持列表请以各上游仓库文档为准。
4. **外链检索备忘**：部分工程博客（如 vLLM 官方博客）存在 URL 路径迁移情况，课程录像（如 MIT 6.5940 跨学年开课页）也会按年份更新；若偶遇外链失效，直接检索文中保留的精确英文标题或 arXiv 编号即可定位。

## 三、参与贡献

非常欢迎社区同行通过 GitHub Issue 或 Pull Request 共同打磨本书，尤其欢迎以下方向的贡献：

- **纠错与公式校核**：指出任意章节中的数学笔误、单位换算疏漏或代码细节问题；
- **补充一手资料与图示**：提供更清晰的原理图解、新近顶会论文的口径补充或更准确的国产芯片软件栈信息；
- **修复失效链接**：同步更新搬家或改版的官方文档、课程录像与仓库路径；
- **分享真实工程归因案例**：欢迎分享你在生产环境或跨芯片迁移中完成的完整 Profiler 归因与优化复盘。
