## Non-goals

- 不扩展为覆盖所有国产平台的完整实机教程。
- 不伪造 GPU/NPU 编译、性能、精度或锁定环境的验证成绩。
- 不修改上游英文原文、现有许可证或笔记/进度存储协议。
- P1 源稿修订期间未提交或发布；后续提交、推送与 GitHub Pages 发布已由用户单独授权。不启动替代站点。

## Constraints

- 权威源稿在 README.md、docs/modules/ 与 tools/；site-src/、site/ 仅在所有并行编辑完成后由主代理统一生成。
- 每名代理只修改指定文件；构建器、首页、统一约定、导航、样式与计划由 lead 独占。
- 使用现有 Python 标准库测试和 MkDocs 环境；不为内容评审安装大型 GPU 软件栈。
- 本轮实际可验收的完整黄金路径是 CPU mock SSE；GPU/NPU 示例分别写清语法检查、环境依赖与待实机验证。
