# 跨芯片对比报告模板

> 用途：第 30 章建立初稿，第 31 章复用同一份报告和原始记录，补证据等级、重复运行与单点优化验收，不另写平行报告。
> 填写规则：每节有内容；未测写“待补测 + 触发条件”。算例为 D 级，单次真实数据为 B 级，多次同条件数据才可为 A 级。
> 统一口径：[跨章节实验约定](../../experiments.md)。历史实测对旧条件仍有效，换环境须重新核验，不覆盖旧数据。
